# 7. Project Documentation

# FitBuddy – AI Fitness Plan Generator

## 1. Introduction

FitBuddy is a web-based AI application designed to generate personalized workout plans and nutrition guidance based on user information and fitness goals.

## 2. Problem Statement

Creating a suitable workout plan manually can be difficult for beginners. FitBuddy provides an easy way to generate a structured fitness plan using AI.

## 3. Objectives

- Generate personalized workout plans.
- Provide nutrition guidance.
- Store user information.
- Collect feedback.
- Provide admin access to user information.

## 4. Technologies Used

- Python
- FastAPI
- HTML
- CSS
- JavaScript
- SQLite
- Google Gemini AI

## 5. System Modules

### User Profile
Collects user details.

### AI Workout Plan
Generates workout plans using Gemini AI.

### Nutrition
Provides nutrition guidance and meal ideas.

### Feedback
Collects ratings and comments.

### Admin
Displays saved users and feedback.

## 6. Database

SQLite database is used to store user profiles, fitness plans and feedback.

## 7. Advantages

- Easy to use
- AI-powered
- Personalized plans
- Simple interface
- Feedback support
- Admin management

## 8. Future Enhancements

- User authentication
- Mobile application
- Progress tracking
- Exercise video recommendations
- Advanced nutrition tracking

## 9. Conclusion

FitBuddy provides a simple AI-based solution for generating personalized fitness plans and nutrition guidance. The system combines FastAPI, SQLite and Gemini AI to provide an interactive fitness planning experience.
