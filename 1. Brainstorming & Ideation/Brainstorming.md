# 1. Brainstorming & Ideation

## Project Title
FitBuddy – AI Fitness Plan Generator

## Problem Statement
Many people find it difficult to create a proper workout and nutrition plan based on their personal goals.

## Proposed Solution
FitBuddy is an AI-based web application that generates personalized fitness plans and nutrition guidance based on user information.

## Main Idea
The user enters:
- Name
- Age
- Height
- Weight
- Fitness Goal

The system uses Gemini AI to generate a personalized workout plan.

## Objectives
- Generate personalized workout plans
- Provide nutrition guidance
- Save user profiles
- Collect user feedback
- Allow admin to view users and feedback

## Technologies
- Python
- FastAPI
- HTML
- CSS
- JavaScript
- SQLite
- Google Gemini AI
