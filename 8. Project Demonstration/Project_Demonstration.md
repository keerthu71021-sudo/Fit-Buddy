# 8. Project Demonstration

## Demonstration Steps

### Step 1
Open the FitBuddy application.

### Step 2
Enter the user's:
- Name
- Age
- Height
- Weight
- Fitness Goal

### Step 3
Click:

Create My Plan

### Step 4
The system creates the user profile.

### Step 5
Gemini AI generates the workout plan.

### Step 6
Open the Nutrition section to view nutrition guidance.

### Step 7
Submit feedback using the Feedback section.

### Step 8
Open the Admin section and enter the admin token.

### Step 9
View saved users and their feedback.

## Expected Output

The application should successfully display:
- User profile
- AI workout plan
- Nutrition guidance
- Meal ideas
- Feedback confirmation
- Admin user information
