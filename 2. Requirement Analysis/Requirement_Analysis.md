# 2. Requirement Analysis

## Functional Requirements

1. User can enter personal details.
2. User can enter fitness goals.
3. System creates a user profile.
4. System generates an AI workout plan.
5. System provides nutrition guidance.
6. User can submit feedback.
7. Admin can view saved users.
8. Admin can view user feedback.

## Non-Functional Requirements

- The application should be easy to use.
- The system should respond quickly.
- User data should be stored safely.
- The application should work on modern web browsers.
- The interface should be responsive.

## Hardware Requirements

- Computer/Laptop
- Minimum 4 GB RAM
- Internet connection

## Software Requirements

- Python
- FastAPI
- SQLite
- Web browser
- Google Gemini API
- VS Code
