# 6. Project Testing

## Testing Objective

Testing is performed to make sure that all FitBuddy features work correctly.

## Test Cases

| Test Case | Input | Expected Result |
|---|---|---|
| User Registration | Valid details | Profile created |
| Empty Name | Empty name | Validation error |
| Invalid Age | Invalid value | Validation error |
| Workout Generation | Valid profile | AI plan generated |
| Nutrition | Valid profile | Nutrition guidance displayed |
| Feedback | Rating + comment | Feedback saved |
| Admin Login | Correct token | Users displayed |
| Admin Login | Wrong token | Unauthorized message |

## Result

All major application functions are tested and errors are corrected during development.
